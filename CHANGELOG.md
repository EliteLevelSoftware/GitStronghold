# Changelog

## 2.0.0

GitStronghold 2.0.0 replaces the Electron 1.1.0 app with a .NET and Avalonia build.

- Offline snapshot of a GitHub user, organization, or single repository
- Profile, avatar, every file on every branch, releases with notes and assets, gists, and repository metadata
- Offline browser for source and sanitized markdown
- Token stored with the operating system secret store
- Incremental backup, a movable vault folder, and a completion notice
- Self-update from GitHub releases when a release exists
